## Selection Criteria

Races are ranked using the following structural criteria only. No criterion favors any party, candidate, or ideology.

| Criterion | What it measures |
|---|---|
| **Electoral significance** | Seat type (federal > state), whether the race is open (no incumbent), electoral scope |
| **Claim density** | Volume of verifiable factual claims likely to be generated by an active competitive race |
| **Data readiness** | Neutral, record-based official roster source exists (state SOS, certified results, official filing record) |
| **Timing** | Race is active or primary/runoff falls within the next 90 days |
| **Pipeline leverage** | Builds on existing infrastructure or meaningfully extends geographic/office coverage |

All races require a neutral primary-record source for roster data before onboarding begins. See `docs/ONBOARDING_PLAYBOOK.md` and the source admission policy in `Agents.md`.
